FAQ

자주 묻는 질문

어떻게 설치하나요?

위의 다운로드 버튼으로 설치 파일을 받아 실행하면 돼요. 설치를 누르고 끝나면 시작하기를 누르세요. 설치 위치는 기본이 Program Files이고, 바꿀 수도 있어요.

파란 보호 화면이 떠요

새로 만든 앱이라 윈도우가 한 번 확인하는 화면이에요. 추가 정보를 누른 뒤 실행을 누르면 설치가 계속돼요.

업데이트는 어떻게 하나요?

새 버전이 나오면 오른쪽 위에 알림창이 떠요. 바뀐 내용을 읽고 다시 시작해서 업데이트를 누르면 끝이에요.

어떤 컴퓨터에서 쓸 수 있나요?
